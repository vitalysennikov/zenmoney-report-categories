# ZenMoney — отчёт по категориям

Локальная HTML-страница для [ZenMoney](https://zenmoney.ru/) — отчёт по категориям расходов/доходов с фильтрами по счетам и проектам. Один файл, без сборки и без своего сервера — работает прямо в браузере (в т.ч. на смартфоне).

**Текущая версия: 1.15**

**Открыть:** [vitalysennikov.github.io/zenmoney-report-categories](https://vitalysennikov.github.io/zenmoney-report-categories/) — или скачай `index.html` и открой локально (двойной клик, `file://`).

Токен вводится каждый раз в поле на странице (по кнопке или Enter) и нигде не сохраняется — ни на сервере (сервера нет), ни в самой странице. Получить токен: [zerro.app/token](https://zerro.app/token) — авторизуйся своим аккаунтом ZenMoney и скопируй токен со страницы.

> Итог, круговая диаграмма и свёрнутое дерево категорий сразу после загрузки — панель фильтров ещё не тронута (значения по умолчанию).

## Возможности

**Период и тип**
- три режима периода: Месяц, Год, Диапазон (произвольные даты «С»/«По»);
- у Месяца и Года — кнопки `‹`/`›` для быстрого перехода на соседний период;
- переключатель Расходы / Доходы.

**Дерево категорий**
- раскрывающиеся подкатегории (`▸`/`▾`), сумма у родителя включает все дочерние; ссылки «Развернуть все категории» / «Свернуть все» над таблицей;
- у каждой категории — иконка на цветном кружке (цвет и эмодзи — из данных ZenMoney); если у категории нет своей иконки — кружок с первой буквой названия;
- доли в двух колонках: % от родителя и % от общего итога;
- прямые траты категории, у которой есть подкатегории, показываются отдельной строкой «без подкатегории».

**Круговая диаграмма**
- топ-7 категорий верхнего уровня + «Остальное», цвета из ZenMoney, легенда с % и суммой.

**Транзакции по категории**
- любая листовая строка раскрывается кликом и показывает список отдельных транзакций (дата, получатель/комментарий, проект, счёт, сумма);
- каждая транзакция дополнительно раскрывается — показывает все доступные поля: категория, проект, счёт, получатель, исходное название получателя (если отличается), мерчант, комментарий, сумма в исходной валюте, MCC-код, статус hold, наличие QR-кода, ID транзакции.

> Первая транзакция в «Продукты» раскрыта — под ней весь набор полей (категория, счёт, получатель, MCC, ID и т.д.), а не только дата/сумма, как в свёрнутом виде.

**Вычет возвратов**
- если у категории настроен только один тип (Расходы либо Доходы) и по ней проходит операция с противоположным знаком — это возврат: сумма вычитается из «родного» отчёта категории и не дублируется в противоположном;
- отдельный свёрнутый список «Возвраты» под деревом категорий — показывает все такие операции независимо от текущего фильтра Расходы/Доходы.

**Фильтр по счетам**
- список счетов с метками 🟢 «в балансе» / 🟡 «не в балансе» / 📦 архивный; по умолчанию отмечены счета «в балансе», как в самом ZenMoney;
- перевод между счетами, где ровно один из двух — в текущей выборке, можно (по чекбоксу) учитывать как обычный расход/доход; список всех таких переводов, попавших под границу выборки, всегда виден в отдельном свёрнутом блоке с разбивкой «Пришло (+)» / «Ушло (-)».

> Раскрыт список счетов («Заначка» не отмечена — она вне баланса) и оба нижних блока: один возврат по «Продукты» и два перевода в/из «Заначки» (одна из которых пересекает границу выборки).

![Фильтр по счетам, блоки «Возвраты» и «Переводы вне выборки»](screenshots/refunds-transfers.png#gh-light-mode-only)
![Фильтр по счетам, блоки «Возвраты» и «Переводы вне выборки»](screenshots/refunds-transfers-dark.png#gh-dark-mode-only)

**Фильтр по проектам**
- «проект» — любая дополнительная категория транзакции, не только `#Проекты`; дерево фильтра с коллапсом; три режима — все / только выбранные / кроме выбранных.

> Режим «только выбранные», отмечен один #Ремонт — итог и дерево сузились до 2 130 ₽ (одна категория вместо пяти), в строке над диаграммой появился активный фильтр.

![Фильтр по проектам: только #Ремонт](screenshots/filter-projects-include-dark.png#gh-dark-mode-only)

> Режим «кроме выбранных», отмечены оба существующих проекта — из отчёта исключены все транзакции с любым проектом, остались только «чистые».

![Фильтр по проектам: кроме #Работа и #Ремонт](screenshots/filter-projects-exclude-dark.png#gh-dark-mode-only)

**Экспорт в CSV**
- шапка с параметрами отчёта → сводная таблица по категориям → список транзакций; разделитель полей `;`, дробная часть — через запятую (для Excel/LibreOffice).

## Технические детали

- Один файл, без сборки — vanilla JS, CSS-переменные для тёмной/светлой темы.
- Данные тянутся один раз (`POST /v8/diff/` к `api.zenmoney.ru`) и пересчитываются в браузере при смене любого фильтра — без обращений к серверу.
- CORS у `api.zenmoney.ru` открыт, поэтому запросы проходят и из `file://`.
- Скриншоты в этом README сгенерированы на фиктивных данных: `dev/fixture.js` подменяет ответ API, `dev/make-screenshots.sh` рендерит страницу через Playwright (light + dark, `--color-scheme`) и сохраняет PNG в `screenshots/`.
